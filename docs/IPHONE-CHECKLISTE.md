# Auf dem iPhone prüfen

Das kann ich am PC nicht testen. Bitte einmal durchgehen und Probleme einfach aufschreiben (Punkt + was passiert ist).

- [ ] **Installation**: Seite in Safari öffnen → Installationsanleitung erscheint → Teilen → Zum Home-Bildschirm → Symbol (Dalmatiner auf Türkis) erscheint.
- [ ] **Vollbild & Safe Areas**: App über das Symbol öffnen. Keine Safari-Leisten. Nichts wird von der Notch / Dynamic Island oder dem Home-Balken unten verdeckt. Hell und Dunkel (Kontrollzentrum → Dunkelmodus) sehen gut aus.
- [ ] **Kroatische Stimme**: Beim ersten Start den Lautsprecher antippen – „Dobar dan! Ja sam Točka.“ ist zu hören. In einer Lektion: 🔊 normal und 🐢 langsam klingen richtig. (Stummschalter aus!)
- [ ] **Tippen**: In einer Schreibaufgabe ins Feld tippen. Die Seite zoomt nicht hinein. Die Leiste mit č ć đ š ž ist sichtbar und fügt die Buchstaben ein. Der Prüfen-Knopf bleibt über der Tastatur sichtbar. Das iPhone „verbessert“ keine kroatischen Wörter.
- [ ] **Flugmodus**: Flugmodus an, App ganz schließen (nach oben wischen), neu öffnen → App startet und eine Lektion läuft.
- [ ] **Fortschritt nach Neustart**: Lektion schaffen, App ganz schließen, neu öffnen → XP, Streak und Kronen sind noch da.
- [ ] **Lektion unterbrechen**: Mitten in einer Lektion kurz zu einer anderen App wechseln und zurück → die Lektion geht an derselben Stelle weiter.
- [ ] **Update kommt an**: Nachdem ich eine neue Version veröffentlicht habe: App öffnen, kurz warten, schließen, neu öffnen → in Einstellungen → Über Pomalo steht das neue Datum.
- [ ] **Export/Import**: Einstellungen → Als Datei sichern → in „Dateien“ speichern. Dann Sicherung laden → Datei wählen → Sicherheitsabfrage → Fortschritt ist wieder da.
